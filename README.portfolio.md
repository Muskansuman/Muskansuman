## About this project

Professional single-page portfolio built with **HTML, CSS, and JavaScript**.  
All content is managed in `config.js` — no framework required.

### Features

- Responsive, professional design
- Project highlights with metrics
- Experience timeline
- Skills and tech stack sections
- Contact and social links
- Deployed on Netlify and GitHub Pages

---

## Run locally

```bash
git clone https://github.com/Muskansuman/new.git
cd new
python3 -m http.server 8888
```

Open [http://localhost:8888](http://localhost:8888)

---

## Customize

Edit **`config.js`** to update:

- Name, title, and bio
- Projects and metrics
- Skills and experience
- Email, LinkedIn, GitHub links

---

## Project structure

| File | Purpose |
|---|---|
| `index.html` | Page layout |
| `style.css` | Professional styling |
| `config.js` | All portfolio content |
| `script.js` | Dynamic rendering |
| `assets/` | Images and preview screenshots |
| `404.html` | Custom 404 page |

## Deploy

GitHub Pages deploys automatically via GitHub Actions when you push to `main`.

**Enable once:** Repo **Settings → Pages → Build and deployment → Source: GitHub Actions**
