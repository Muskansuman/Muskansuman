# Portfolio Website Setup

Professional single-page portfolio — source files in this repo.

## Live site

**https://polite-semifreddo-820f57.netlify.app/**

## Files

| File | Purpose |
|---|---|
| `index.html` | Page structure |
| `style.css` | Styling |
| `config.js` | Portfolio content (edit this) |
| `script.js` | Renders content + navigation |
| `404.html` | GitHub Pages 404 page |

## Customize

Edit `config.js` to update name, projects, experience, and links.

## Deploy

### Netlify (connected to this repo)

Push to `main` — Netlify auto-deploys if the repo is linked.

### GitHub Pages

1. **Settings → Pages → Source: GitHub Actions**
2. Push to `main` — workflow deploys automatically
